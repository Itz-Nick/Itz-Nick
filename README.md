## Projetos em destaque

### [NikoLight](https://github.com/Itz-Nick/Niko-Light-official)

Jogo de estratégia para navegador com combate em tempo real, unidades, formações e ondas de inimigos. O código reúne sistemas de renderização, combate, economia e progressão. O modo cooperativo e parte do modo Aventuras seguem em desenvolvimento.

**Tecnologias:** TypeScript · Vite · Canvas 2D

### [ECHO//DUNGEON — laboratório de agentes](https://github.com/Itz-Nick/Echo_Agentes_De_Ia)

Experimento de desenvolvimento de um roguelike para navegador e de organização do trabalho com agentes de IA. O repositório contém código para geração de salas, combate e interface, além de planejamento e contratos entre sistemas.

**Tecnologias:** TypeScript · Vite · HTML · CSS · Canvas 2D

### [NeoWorld](https://github.com/Itz-Nick/NeoWorld)

Projeto experimental de estratégia e simulação com mapa, câmera e sistemas de mundo e economia. O projeto está em desenvolvimento; o roadmap distingue a base implementada das próximas etapas.

**Tecnologias:** TypeScript · Vite · Canvas 2D
